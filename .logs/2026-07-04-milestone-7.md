# Milestone 7 - Export service

## Goal

Provide backend export endpoints and frontend export controls for `.ply` and `.glb` artifacts while preserving explicit labels for real versus placeholder/debug outputs.

## Implementation notes

- Added `POST /projects/{project_id}/exports` and `GET /projects/{project_id}/exports`.
- Real exports copy existing PLY/GLB artifacts into the project `exports/` folder.
- Placeholder exports are only allowed from `metadata/reconstruction_spike.json` when `allow_placeholder` is true.
- Placeholder PLY/GLB files include explicit warnings that they are not real reconstructions.
- Export metadata is written under `metadata/exports/` and records source artifact, export format, artifact label, status, generated time, warning, and download URL.
- The frontend viewer now exposes export buttons beside downloadable artifacts and refreshes the artifact list after export.
